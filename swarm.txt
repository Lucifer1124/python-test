On the Manager terminal:
docker swarm init

Output will look like:
Swarm initialized
To add a worker to this swarm, run:
docker swarm join --token SWMTKN-1-xxxxxxxxxxxxxxxxxxxx 192.168.1.10:2377 //Copy this command


Go to the Worker terminal:
docker swarm join --token SWMTKN-1-xxxxxxxxxxxxxxxxxxxx 192.168.1.10:2377

If successful:
This node joined a swarm as a worker.


Back on the Manager:
docker node ls

Jenkins already pushed the image to Docker Hub:
docker pull yourdockerhub/flask-app:latest

On the Manager:
docker service create \
--name flask-service \
--replicas 2 \
-p 5000:5000 \
yourdockerhub/flask-app:latest
